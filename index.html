01 What I’m building

Ravix.

Coding agents, now multiplayer.

Your agent has the context. Your team doesn’t.

Decisions get made inside one person’s agent session. By the time the work becomes a pull request, the team sees the result, not the conversation that shaped it.

Ravix fixes that. Teammates join the same Claude Code or Codex thread, guide the agent while it works, and try the running app together, before anyone opens a pull request.

I’m building it with my co-founder and brother, Rushabh Singwi. Ravi Inc. is backed by South Park Commons, where I’m a Founder Fellow.
